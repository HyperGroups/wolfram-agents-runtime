🔮 LLMGraph Runtime Monitor

Wolfram LLMGraph 编程模型的 LangGraph 运行时 - 实时可视化 LLM 工作流执行

📊 这是什么

实时监控界面，展示 LLMGraph 的执行过程。支持声明式图定义、自动依赖推断、并发调度。

🎯 主要功能

  • 实时节点状态可视化
  • 流式 token 显示
  • 成本估算（USD）
  • 多运行对比
  • SVG 缩放/平移

🚀 快速开始

  • 选择左侧 Notebook
  • 在 Input JSON 填写参数
  • 点击 ▶ Run 执行
  • 观察节点逐个亮起

⌨️ 快捷键

  • Ctrl+Enter - 运行图
  • Esc - 取消选择节点
  • 鼠标滚轮 - 缩放画布
  • 拖拽空白区 - 平移画布
💡 提示： 首次使用？点击任意节点查看详情，在 History 中选择历史运行，或勾选多个运行进行对比。点击右上角 ? 可随时重新打开此介绍。
