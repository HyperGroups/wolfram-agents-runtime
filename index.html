✨ 核心特性

🎯 声明式图定义

使用 JSON 或 Python API 定义 LLM 工作流，依赖自动推断，并发调度执行。

🔌 多后端支持

支持 Anthropic Claude、OpenAI、Qwen、DeepSeek 等 6 个 LLM 后端，可混合使用。

📊 实时监控

Web 界面实时展示图执行过程，支持流式 token 显示、成本估算、多运行对比。

🔄 失败传播

FailedNode 和 CanceledNode 自动传播到下游节点，独立的错误处理语义。

⚡ ListableLLM

支持并行 map LLM 调用过列表输入，高效处理批量任务。

🎨 双引擎 Parity

与 Wolfram 原生 LLMGraph 双向验证，确保语义一致性。

# 安装依赖 cd wolfram-agents-runtime uv venv --python 3.12 uv pip install -e ".[dev]" # 配置 API Key（任选其一） export ANTHROPIC_API_KEY=sk-ant-... export DASHSCOPE_API_KEY=sk-... # 启动监控界面 python -m wolfram_llmgraph.cli serve examples/bestpoem.json --open
